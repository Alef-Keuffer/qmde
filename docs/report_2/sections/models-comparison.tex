\subsection{Double implementation}\label{sec:models-comparison}

To let every team member work with the problem, we developed two implementations: one using BESSER and one using
EMF, in \texttt{besser/} and \texttt{emf/}.

The main difference is how they handle exam weights. The EMF implementation uses each exam's weight as the cost of
leaving it unscheduled. The BESSER QUBO does not use exam weights: it assigns every exam to a slot and minimizes
conflicts. Thus, when not all exams can be placed without conflicts, EMF may leave an exam out, while BESSER keeps
all exams and accepts the fewest possible conflicts. Their results are not directly comparable because they
optimize different objectives.

The implementations also use different modeling technologies: EMF uses Xtext, ATL and Acceleo; BESSER uses
Python B-UML transformations and BESSER's Qiskit generator.
